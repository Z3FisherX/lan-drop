# LAN Drop · 现场扫码收件箱

把一台 Windows 电脑变成现场收件箱。工作坊、培训或小组活动结束前，主办方把二维码投到屏幕上，参与者扫码交文件，文件直接存到主办方选定的本地目录。

> Collect files from people on the same local network. Start an inbox on your computer, show its QR code, and let guests upload from their browser. Files land directly in the folder you choose.

## 快速开始

1. 在主机上安装 [Node.js 22 LTS](https://nodejs.org/)，下载或克隆本项目后，双击 `start-inbox.cmd`。首次启动需要联网安装依赖。
2. 用主机浏览器打开终端显示的管理地址，默认是 `http://127.0.0.1:38471/`。
3. 点击「选目录并开始」，选好本地目录后就会显示收件二维码。「手动填写路径」也可以开始收件。
4. 点击二维码放大投屏，或复制投递链接。同一局域网内的访客扫码后点击「选择文件并上传」，确认所选文件后即开始上传。
5. 在主机页面查看本次收到的文件，结束时点击「结束收件」。原二维码随即失效，已完成的文件保留在所选目录里。

也可以在项目目录里用 Node.js 自带的 npm 启动，再打开同一个本机管理地址。

```sh
npm install --no-package-lock
npm start
```

端口被占用时，可以运行 `npm start -- --port 8088`。单文件大小默认上限为 10 GiB，可用 `--max-size` 调整，单位是 GiB。

## 主机和访客各自能做什么

| 主机管理页 | 访客投递页 |
| --- | --- |
| 选择接收目录，开始或结束一次收件 | 打开有效链接后选择文件上传 |
| 展示二维码、切换局域网地址、复制链接 | 查看自己这次上传的进度和结果 |
| 查看本次收到的文件名、大小和时间 | 仅有上传权限 |

- 管理页只接受本机回环连接。访客链接只授予当次收件的上传权限。
- 上传完成后文件才出现在收件列表。同名文件自动加数字后缀，已有文件会保留。
- 结束收件后，未完成的上传会被中止。重开收件会生成新链接。管理页的收件记录只保留当前或最近一次会话，重启也会清空记录，磁盘上的文件会保留。
- 访客使用浏览器即可，无需账号或应用。依赖安装完成后，页面、二维码和文件传输可在局域网内运行。

## 现场网络

- 开始前先在另一台设备上试扫一次。访客需要能从局域网访问主机，部分访客 Wi-Fi 会隔离设备。主机有多个网卡时，可以展开「连接选项」切换到访客能访问的地址。
- Windows 防火墙若弹窗，允许专用网络访问。访客应使用二维码或投递链接，`127.0.0.1` 是主机的本机管理地址。
- MVP 使用 HTTP，适合可信局域网。知道有效投递链接且能访问主机的人即可上传。请按现场参与范围分享二维码。
- 收件目录需要可写，并支持硬链接，例如 Windows NTFS。上传中断后需要重新提交。

## 开发与验证

```sh
npm run check:syntax
npm test
```

项目使用 Node.js HTTP、原生 HTML/CSS/JavaScript 和本地二维码生成。文件以流式方式写入临时文件，完成后再发布到目标目录。集成测试覆盖访客权限、关闭和重开收件、文件完整性及已有共享模式。使用 Yarn Classic 时，可以运行 `yarn install --frozen-lockfile` 按锁文件安装。

原有的目录共享仍可通过 `node server.js` 使用，参数见 `node server.js --help`。现场扫码收件通过 `node server.js --inbox` 启动。
